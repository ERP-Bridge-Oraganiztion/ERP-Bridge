# Contributing to ERP Bridge

Thank you for your interest in contributing to ERP Bridge!

We welcome contributions from developers, designers, testers, ERP consultants,
and technical writers.

---

# Code of Conduct

All contributors are expected to

- Be respectful
- Be professional
- Provide constructive feedback
- Help other contributors
- Follow project standards

---

# Before You Start

Please

- Read the README
- Review the PRD
- Understand the architecture
- Check open issues
- Discuss major changes before implementation

---

# Development Workflow

↓

↓

↓

Write Tests

↓

↓

Commit Changes

↓

Push Branch

↓

Create Pull Request

---

# Branch Naming

Feature

feature/login-module

Bug Fix

bugfix/export-error

Documentation

docs/api-spec

Hotfix

hotfix/security-patch

Release

release/v1.0.0

---

# Commit Message Convention

Format

<type>: <description>

Examples

feat: add CSV connector

fix: resolve validation bug

docs: update README

refactor: improve migration engine

test: add API tests

style: format source code

---

# Pull Request Checklist

Before submitting a Pull Request

- [ ] Code builds successfully
- [ ] Tests pass
- [ ] Documentation updated
- [ ] No sensitive information committed
- [ ] Code follows project standards
- [ ] No merge conflicts

---

# Coding Guidelines

Backend

- Node.js 20
- Next.js
- Clean Architecture
- SOLID Principles

Frontend

- React
- TypeScript
- Functional Components
- Reusable UI Components

---

# Testing Requirements

Every new feature must include

- Unit Tests
- Integration Tests (where applicable)

---

# Documentation

If your contribution changes functionality

Please update

- README
- API Specification
- Technical Documentation

---

# Issue Reporting

When reporting bugs include

- Description
- Expected Result
- Actual Result
- Screenshots (if applicable)
- Steps to Reproduce
- Environment

---

# Feature Requests

Please include

- Problem Statement
- Proposed Solution
- Benefits
- Possible Implementation
